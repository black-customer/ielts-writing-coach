❓ 常见问题
  • AI 功能要钱吗？内置范文/审题课全程免费；AI 精批和逐段点评用你自己的 DeepSeek key（③诊断室 → AI 设置粘贴一次）。
  • 数据会丢吗？数据只在本机浏览器。换电脑/清缓存前，用「⑧ 进度·词本」的备份导出。
  • 小作文图表哪来的？原书扫描页；克隆仓库后运行 python download-t1-charts.py 获取。
  • 训练营怎么做题？选一张卡 → 直接看范文 → 逐段学 → 写完「全文送去诊断室」。
