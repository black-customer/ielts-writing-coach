# 隐私与数据说明

本工具（IELTS Writing Coach）是一个**纯本地离线应用**。你的隐私边界如下：

## 数据存储

- **全部学习数据只存在你自己的电脑浏览器里**（localStorage）：诊断记录、训练进度、词本收藏、草稿、AI 设置等，不上传到任何服务器。
- 仓库与部署站点**不含任何后端**，没有账号系统，没有数据收集，没有统计埋点。
- 清除浏览器站点数据 = 删除全部学习数据。请定期使用「⑧ 进度·词本」的备份导出功能。

## API 密钥

- AI 精批与 AI 导师点评功能使用**你自己申请的 DeepSeek API key**。
- key 只保存在你浏览器的 localStorage（或你本地的 `tool/js/config.js`），**不会被发送到除 DeepSeek 官方接口以外的任何地方**。
- 公开仓库中的 config.js 不含任何密钥（密钥已置空）。
- 你粘贴的作文只随精批请求发往 DeepSeek 官方 API；使用本地大模型（如 Ollama）时可做到完全不联网。

## 内容边界

- 剑桥雅思真题（题目、图表、官方样卷）与前考官 Simon 的课程内容仅供个人学习使用，其版权不属于本仓库 MIT 授权范围（详见 [LICENSE](LICENSE) 末尾的内容边界说明）。
- 公开仓库不携带剑桥真题 PDF 与原书扫描图；`tool/img/t1/` 下的学习用图表请通过 `python download-t1-charts.py` 自行获取。
- `models/` 目录下的范文与教学包为本工具写作体系原创生成内容，随 MIT 授权共享。

如对隐私或内容边界有疑问，请在本仓库提 Issue。
