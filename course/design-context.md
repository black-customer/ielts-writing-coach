# Simon 之后 · 课程界面设计交接

更新：2026-10-01。范围仅为 `course/`；这是既有视觉世界的课程延伸，不替代根目录 `PRODUCT.md`、`DESIGN.md` 或 `.impeccable/`。

## Overview

沿用“安静、精密的写作工作台”：雾灰背景、纸白内容、墨色正文、深蓝操作；中文界面使用系统 UI 字体，连续英文示例和作答使用 Georgia。课程面向已学过 Simon 或同类基础课、约 5.5 分并希望向 7.5 分以上提升的学习者。分数是训练目标，须由独立作品与外部评阅检验。

这是代码主导的实现，没有已批准的视觉稿。已制作 8 课、合计 1781.037334 秒（约 29.7 分钟）视频与训练手册；播放器将总时长四舍五入显示为 30 分钟。第 09–32 课是规划，不能呈现为已制作课程。

## Typography

界面为 `'Segoe UI','Microsoft YaHei',sans-serif`（15px / 1.7）；标题为 `clamp(26px,2.3vw,36px)`、600 字重、1.4 行高。目录题名 14px、辅助信息 12px；数字序号与时间使用等宽数字。`.reading` 限宽 74ch、行高 1.9；`.script-example` 为 Georgia（19px / 1.7）。英文练习题中的短片段保留界面字体，不把所有英文强制改为长文排版。

## Layout

- `.workspace` 上限 1700px，默认两列：260px 目录与弹性正文。`.syllabus` 顶部 sticky、最高 100vh、内部纵向滚动。正文内边距 32px 40px 48px。
- `.practice-layout` 默认弹性写作纸面加 280px 核查栏，间距 32px。视频始终宽度 100%、16:9，正文保留足够横向空间供实际媒体显示。
- 1500px 起，正文水平内边距为 56px，核查栏为 320px。
- 1150px 以下，目录为 220px，正文内边距 28px 24px；练习变成一列，核查栏内部暂用两列。
- 760px 以下，目录回到文档流，课程按钮横向滚动；规划与介绍在目录内隐藏。正文内边距 24px 20px，核查内容顺序向下排列，写作纸面内边距 20px。章节亦可横向滚动。

上述是课程局部断点，不扩展根设计文档对旧工作台的桌面验收范围。390px 截图中视频按比例缩小，幻灯片小字应通过原生全屏或逐字稿阅读，不将缩略画面宣称为完整手机阅读体验。

## Elevation & Depth

常驻界面不使用阴影；纸面和浅底提供层次，细线分隔目录、媒体操作、核查与底部导航。章节选中使用实色，课程选中使用软底；不添加悬停抬升或装饰性发光。

## Shapes

按钮、目录项和文本区为 8px 圆角；视频与写作纸面为 12px。分隔与字段描边通常为 1px。键盘焦点为 3px 深蓝 outline、4px 偏移。全局按钮悬停会应用 `brightness(.96)`，组件另有浅底悬停状态；课程没有新引入场动画，章节平滑滚动仅在未请求减少动态效果时启用。

## Components

- `.lesson-choice` 显示序号、标题、时长与“待练习 / 练习已完成”，通过 `aria-current` 标明当前课。`.chapters` 是跳转真实视频时间的按钮，不是播放装饰。底部上/下一课在边界禁用。
- `#lesson-video` 使用浏览器原生 `controls`、`playsinline`、`preload="metadata"`。保留播放、音量、进度与全屏控制；同步字幕已在画面中，页面另提供字幕下载。播放器未添加外部 VTT `<track>`，不能声称网页支持字幕轨切换。
- `.study-tabs` 切换独立练习、讲解逐字稿与教学依据；采用 `aria-selected` 与 roving tabindex，支持左右方向键、Home、End。切课回到独立练习，标题接收焦点。
- `.writing-sheet` 保留三个独立字段：`#first-draft`、`#revision`、`#priority`。分别为 8 / 6 / 2 行，允许纵向拖动；宽度 100%，最小高度 80px、最大高度 600px，16px 内边距，字体为 `17px/1.8 Georgia,'Microsoft YaHei',serif`。占位符使用中文 UI 字体（14px）。改写不能覆盖初稿，下一次目标仅记录一项问题。
- `.practice-guide details` 默认关闭，切课再次关闭，参考讲评由学习者主动展开。换题任务保留原定安排；第 01、08 课含 24 小时 / 3 天等延迟复测，第 08 课另含 7 天套题与外部评阅。
- `#save-status` 使用可见文字和 `role="status"` 表达保存中、已保存、恢复与失败。350ms 输入防抖保存，切课与离开前保存；本机存储 key 为 `iwc_course_simon_after_v1`，各课独立保存初稿、改写、目标与更新时间。存储失败仍可导出 JSON。数据留在当前浏览器，不承诺跨浏览器同步。
- 完成操作要求先留下非空初稿，可撤销；总数与目录只表达练习完成情况。页面文字与导出的 `completionIsNotScore: true` 明确区分完成与分数。
- 使用相对路径、普通脚本与本地 MP4，可直接打开 `index.html`；整个 `course/` 与 `media/` 须一起保留。视频失败显示 `role="alert"` 和下载出口，逐字稿、练习仍可用。外部教学来源链接需要网络。

## Do's and Don'ts

Do 保持视频、独立练习与换题复测的清楚顺序；用文字说明保存和完成状态；将未制作规划与已制作课程区分。Don't 为新课程重写旧工具视觉系统，或将初稿与改写合并成一个字段；不要把完成比例变成成绩承诺。

核查证据：读取 `index.html`、`course.css`、`player.js`、课程数据与媒体清单，比较根产品/设计文档及 `tool/css/workbench.css` / `style.css`，查看 `build/qa/desktop.png`（1440px）与 `mobile.png`（390px）。现有 `player-checks.json` 记录两档无页面横向溢出、无运行时错误，草稿恢复、键盘标签、答案展开与章节跳转通过，以及存储不可用时的可见错误与导出出口。本交接复核证据，不代替全量辅助技术认证。

已知差异：课程辅助灰比根 `muted`（#647080）更深，界面/编辑字号与焦点线宽也是有意的局部适配。旧工具基础 `style.css` 仍声明早期蓝色 palette 和教学语义色，后加载的 `workbench.css` 覆盖共享工作台值；不可把基础声明当成当前所有元素的计算样式，也不可宣称历史颜色已全部清理。此轮仅记录这些既有来源差异，没有修复或改写旧工具、根视觉文档及 sidecar。
