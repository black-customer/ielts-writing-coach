# 写作研习室 · IELTS Writing —— 项目总览与使用说明

## 长期平台范围

本项目默认面向电脑端浏览器。不规划、不开发手机端 App，手机端专项设计、适配和验收不纳入默认开发范围。只有项目所有者明确重新提出手机端需求时，才能调整此约束。不得因通用最佳实践、工具建议或框架能力而自行扩展手机端开发范围。

开发者遵循 [AGENTS.md](AGENTS.md)，保留现有窄屏回退，不主动扩展手机端开发。

## v1.4：连续写作与可执行反馈

- 选题带入 Task、题干和可用图表；换题先保护原稿，首页可继续整篇草稿或恢复保留的草稿。
- 首要改写目标附原句、原因和自查标准；同一句反馈合并，参考改写保持折叠。
- 首页选题列表默认收起；范文、诊断和资料页面改善阅读层级、键盘焦点与明暗主题。
- 56 篇范文的 224 条自查指令和 28 份读图课已审校；教学模板、连接词和表达数量不换算为分数。
- 内置范文可组合搜索、Task、册号筛选与分页；题库支持 Task 1 / Task 2 搜索，详情返回保留位置。
- 改善输入法搜索、AI 手动重试、新手引导、备份验证和导入失败回滚。旧草稿与备份继续兼容。

运行 `python -X utf8 run_checks.py`、`python -X utf8 build_site.py` 和 `npx playwright test` 验收。发布由 GitHub Actions 测试后部署 Pages。交付说明见 [v1.4 验收记录](docs/desktop-ux-v1.4.md)。

## v1.3：根据实际表现推进的训练

打开 `tool/index.html`，从「今日训练」开始：独立作答 → 诊断一个问题 → 针对性练习 → 隔天换题 → 完整答卷验证。

- 八类练习按问题决定写句子、段落或整篇；每类都有原创对比例子和改法讲解。
- 现有 AI 精批可直接提供有原句证据的具体训练目标；离线规则提示与人工自查也能开始练习。
- 到期复测优先；重复问题优先；反复失败时缩小短练习。自查说明可选，未完成作答可保存。
- 辅助练习与独立复测分别记录；连续三次独立换题通过后，安排一份完整新题答卷，可计时并恢复草稿。
- 进度页保留原稿、作答、证据和自查标准，可复制给老师复核或导出 HTML。全部记录进入现有 JSON 备份。

这套流程的目标是提高练习与反馈的有效性。自动分类、AI 评分和自查均有边界，当前没有真实提分试验。研究依据、训练取舍与验收见 [训练策略说明](docs/learning-strategy.md)。

## v1.2：电脑端写作工作台

- 固定侧栏统一八个功能入口，今日任务、草稿和复测放在首页。
- 写作室提供连续全文编辑、自动保存、复制全文、可收起教学面板和专注模式；旧草稿直接恢复。
- 诊断结果可点击批注定位原句，支持重复片段选择、原稿与改写并排查看；原稿和 AI 反馈绑定同一版本。
- 保存失败有明确提示和重试；普通提示不阻断输入，删除与覆盖使用键盘可操作的确认窗口。
- 提供明暗主题；本轮重点验收 1280 / 1440 / 1600px 电脑窗口。

运行入口为 `tool/index.html`。部署构建运行 `python -X utf8 build_site.py`；新增样式与脚本均进入离线预缓存。说明见 [电脑端升级说明](docs/desktop-workbench.md)，视觉规范见 [DESIGN.md](DESIGN.md)。

## v1.1：以改写和换题验证为主的学习流程

打开工具默认进入训练营的「今天，解决一个写作问题」。建议每次按以下顺序练习：

1. **独立尝试**：先用约 8 分钟写开头或关键段落，再打开教学和范文。工具保存独立初稿与辅助使用记录，随时可以对照。
2. **诊断后立即改写**：规则诊断或 AI 精批会自动保存原题、原稿和一个优先目标。用约 10 分钟改写相关句子或段落，写出一句自查证据。
3. **换题复测**：改写自查通过后，24 小时后用另一道同任务类型的题独立作答。之后独立通过则间隔 3 天、7 天继续换题，连续三次后安排整篇验证；失败则次日再试。
4. **核对真实能力**：自查通过不等于达到某个分数。定期用完整限时作文与外部反馈检验；进度页按 Task 1 / Task 2 分别展示 AI 参考分。

短练习、保存和复测安排全部离线可用，无需 API。所有新增记录进入现有 JSON 备份；在「进度·词本」可查看诊断原稿和历次改写。AI 评分仍为参考，尤其未附题干或原图时不能完整评估 TR/TA。

实现与验收说明见 [学习效率优化说明](docs/learning-efficiency.md)。后文原有功能手册中的「范文先行」仍可作为辅助学习路径使用，默认入口已改为先独立作答。

> 目标：**看到任何一道雅思写作题，都知道怎么写；写完任何一篇，都明确知道差在哪。**
> 全部知识体系从前考官 Simon 的全套课程（网站课程全篇 + worksheets + 30 篇 band 9 范文 + 2026 年归档增量课）、《Ideas for IELTS Topics》、顾家北词伙表、剑桥真题 10-13、2023-2026 考场真题回忆中提炼，通过 7 路深度分析 + 人工精读交叉验证。

## 一、最快上手（30 秒）

> **从 GitHub 克隆本仓库后**，两步补齐本地材料（版权原因仓库不带）：
> 1. 剑桥原书 Task 1 图表（28 张）：`python download-t1-charts.py` —— 自动从公开题库拉取原书扫描图到 `tool/img/t1/`，不跑也不影响其他功能；
> 2. AI 精批/导师点评：打开工具 → ③诊断室 → AI 设置，粘贴你的 DeepSeek key（存浏览器 localStorage；仓库中的 config.js 不含密钥）。

**双击打开 `tool/index.html`**（纯本地离线应用，无需联网），你会看到 8 个功能室：

**Task 1 小作文**：写作室和诊断室都有 "Task 1 小作文" 模式——选图表类型会给对应的分段骨架（overview 怎么找、细节段怎么分组），诊断引擎专查小作文硬伤：overview 缺失、照抄题目、"Canada was 19 million tonnes" 主谓错、10 millions、负百分比、无比较语言、时态错误等。

## 三、这套方法的三个核心发现（为什么它能提分）

### 附加：学习系统依据的记忆学设计（2026-09 重构）

- **检索练习/测试效应**：闪卡不是"看中英对照"，而是语境填空式主动回忆；
- **编码特异性**：词伙始终在"题目背景+范文句"里学习和测验，考场遇到类似语境才能自动激活；
- **间隔重复（Leitner）**：认识的卡间隔拉长（1/3/7/14/30 天），不认识的明天回来，"今日复习"只推到期卡；
- **需求驱动**：词伙库按写作场景（表达好处/坏处/原因/解决…）组织——先有表达需求，再给语言。

1. **组织要服务于回答题目**：四段可以作为练习脚手架，但官方没有固定段数或句数。先把任务、立场和主要内容想清楚，再用适合内容的结构表达。
2. **词汇和衔接都看实际使用**：用词应准确、得体并有足够范围；连接词应表达真实关系。范文频率不能变成禁词清单，主题搭配数量不能换算为分数。
3. **观点要得到解释和支撑**：推理、具体细节和例子都可以支撑观点，不要求每个主体段出现 For example。回到原题核验内容是否充分、相关、精确。

## 三点五、评分已用官方样卷校准（2026-09）

从剑10-13 书后答案提取 **27 篇官方样卷**（13 篇 Task 2 + 13 篇 Task 1 考生手写卷，Band 3.5-8，经视觉转录；+ 6 篇考官 9 分范文），让评分系统在**看不到官方分数**的条件下盲评：

- 旧报告在这组校准样本上记录总分 MAE 0.05。样本有限，不能据此保证新作文的评分误差或训练提分效果；
- 旧报告中规则引擎 MAE 0.79。规则是启发式检查，会漏报和误报，尤其不能由标记词、段数或词频判定内容质量；
- GRA 分项 AI 天然略严 0.25，已知悉并在提示词中声明。

详见《knowledge/12-评分校准报告.md》，复跑命令：`node grade-rule.js`（规则）/ 校准语料在 `calibration/`。

## 五、诚实说明（工具的边界）

- 诊断室的机器扫描是**规则启发式**，能可靠抓住硬伤（字数不足、结构失衡、Although...but、逗号粘连、不可数名词、立场缺失、例子缺失、词伙覆盖、Task 1 的 overview 缺失/照抄题目/主谓逻辑等），但**不能替代人工精读**——最终分数由"机器扫描 + 20 项自评清单"共同得出，工具里也明确标注了这一点。
- 剑桥 14/16/18 原书 PDF 是扫描版无文字层，剑 14-18 题干已用网络多源（engnovate / ieltsessaybank / howtodoielts）交叉核实替换记忆版；Task 1 图表类型按调研标注、题干文字需配原书图表。考场真题为考生回忆，个别措辞可能与原题有出入。
- AI 精批为真实 API 调用（key 存于本机 tool/js/config.js，可在「AI 设置」覆盖）；模型评分存在 ±0.5 浮动，与规则诊断+自评交叉使用更可靠。deepseek-flash 为推理模型，精批约需 15-30 秒。
- Simon 原博客已于 2025 年 9 月因托管商倒闭下线，本项目的增量调研全部来自 Wayback Machine 归档实抓（见 knowledge/09）；"9+12 讲"视频课打包为第三方版本，官方课程目录见 09 号文档。
- 视频课（mp4）未转录，但其内容与 PDF 课程/worksheets 完全同源，无信息损失。
