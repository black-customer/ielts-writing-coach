# 写作研习室 · IELTS Writing —— 项目总览与使用说明

> 目标：**看到任何一道雅思写作题，都知道怎么写；写完任何一篇，都明确知道差在哪。**
> 全部知识体系从前考官 Simon 的全套课程（网站课程全篇 + worksheets + 30 篇 band 9 范文 + 2026 年归档增量课）、《Ideas for IELTS Topics》、顾家北词伙表、剑桥真题 10-13、2023-2026 考场真题回忆中提炼，通过 7 路深度分析 + 人工精读交叉验证。

## 一、最快上手（30 秒）

> **从 GitHub 克隆本仓库后**，两步补齐本地材料（版权原因仓库不带）：
> 1. 剑桥原书 Task 1 图表（28 张）：`python download-t1-charts.py` —— 自动从公开题库拉取原书扫描图到 `tool/img/t1/`，不跑也不影响其他功能；
> 2. AI 精批/导师点评：打开工具 → ③诊断室 → AI 设置，粘贴你的 DeepSeek key（存浏览器 localStorage；仓库中的 config.js 不含密钥）。

**双击打开 `tool/index.html`**（纯本地离线应用，无需联网），你会看到 7 个功能室：

| 功能室 | 解决什么问题 |
|---|---|
| ① 审题室 | 贴入任意题目 → 自动判题型 → 四段作战图、立场建议、句式模板、避坑清单、本题观点和词伙弹药，**并可做「✏️ 提纲训练」**（10 分钟审题练习，自动检查立场/观点/例子/题目覆盖度） |
| ② 写作室 | **Task 2 / Task 1 / 🎓 全真模考 三模式**。T2：40 分钟 + 4 段骨架；T1：20 分钟 + 按图表类型给专属骨架；模考：T1 20 分钟结束自动进入 T2 40 分钟。实时字数/句数、草稿保存恢复 |
| ③ 诊断室 | **双模式诊断 + 句子体检 + 🤖 AI 考官精批 + 📋 复盘卡**。规则引擎扫硬伤并高亮定位到句子（原因内联显示）；AI 精批按官方量表给分+逐段点评+最弱段改写示范；诊断结束自动生成**复盘卡**（每条问题→下次动作→方法论出处）；同一题改写可自动对比提升 |
| ④ 训练营 | **核心功能：AI 导师逐段带写，大作文+小作文全覆盖（56 题）**。**矩阵选题**（大/小作文分区 + 题型/图型筛选 + 按册分组）；**56 篇范文+教学包+56 份审题课/读图课全部内置**——从选题到看范文到读图/审题课全程零 API，只有「AI 点评你写的段落」消耗 token；小作文附**内置图表**（28 张 SVG 重绘，数据与原书一致）；写完送诊断室复盘。范文与教学全部遵循「我的写作体系」（知识库 13） |
| ⑤ 弹药库 | 24 个话题 1000+ 条观点、858 条主题词伙、Task 1 全语言库、高频错误对照；**⚡ 闪卡 v2 语境填空**（范文语境+挖空句+渐进提示+间隔重复「今日复习」）；**🕯 填空精读**；词伙库支持**按写作场景浏览**、字号三档、每条附范文用例 |
| ⑥ 题库·范文 | **📑 预生成范文库（56 篇矩阵速查，一键复制去外部验证，小作文附对照图表）** + 剑桥 10-18 **全部真题**（10-13 原书提取 + 14-18 网络多源核实版）+ 2023–2026 考场真题 78 道 + 8 篇逐句标注精读范文 + **Simon 范文全库检索**（大作文 31 篇 + 小作文 45 篇，自动句功能标注） |
| ⑦ 学习路线 | 6.5→7.5 的 4-8 周训练计划 + 五条写作铁律 + 高频错误对照 |
| ⑧ 进度·词本 | 训练记录、总分走势、分项均值统计；**📌 个人系统性错误 Top 5**（按你的历史记录聚合）；收藏本可导出；**💾 全量数据 JSON 备份/导入** |
| 🌙 | 全局暗色模式（右上角切换，记忆偏好） |

**推荐第一次使用流程**：⑥学习路线看计划 → ①审题室贴一道题（或从⑤题库选）→ 点"带着这道题去写作室" → 写完点"去诊断室" → 按修复项改写 → 在③保存记录，到⑦看分数走势。

**Task 1 小作文**：写作室和诊断室都有 "Task 1 小作文" 模式——选图表类型会给对应的分段骨架（overview 怎么找、细节段怎么分组），诊断引擎专查小作文硬伤：overview 缺失、照抄题目、"Canada was 19 million tonnes" 主谓错、10 millions、负百分比、无比较语言、时态错误等。

## 二、知识体系文档（knowledge/ 文件夹）

按顺序读：**00 总纲 → 01 核心方法论 → 03 评分标准**（这三份是"思路"；进阶必读 **13 我的写作体系**——全部预生成范文的写法标准），然后 05 话题思路库 + 06 词伙库（这两份是"储备"，当字典用），04 小作文指南（考前过一遍），02 范文规律 + 10 范文全库指南（仿写时对照），08 考场真题（考前刷题），09 增量调研（进阶精读）。

**重要校准**：官方写作评分标准已于 2023 年 5 月更新（CC9 "very rarely attracts attention"、TR7 "main parts appropriately addressed"、LR7 "and/or idiomatic items"），03 号文档已按现行版校准，官方原文全录见 knowledge/digests/官方评分标准验证.md。

- 思路类知识（怎么想）：题型判定、审题 10 步、立场决策树、观点生成器（16 个万能论证角度）、4 段结构、段内展开法（含 example-led 变体）、隐形衔接 5 法、TR 三动词推进法
- 储备类知识（用什么写）：主题词伙 847 条、话题观点 1000+ 条、开头结尾模板、Task 1 语言库、paraphrase 手法
- 校准类知识（怎么知道好坏）：评分标准逐档解读（含官方原句钥匙）、20 项自评清单、13 大高频错误、范文规律统计

## 三、这套方法的三个核心发现（为什么它能提分）

### 附加：学习系统依据的记忆学设计（2026-09 重构）

- **检索练习/测试效应**：闪卡不是"看中英对照"，而是语境填空式主动回忆；
- **编码特异性**：词伙始终在"题目背景+范文句"里学习和测验，考场遇到类似语境才能自动激活；
- **间隔重复（Leitner）**：认识的卡间隔拉长（1/3/7/14/30 天），不认识的明天回来，"今日复习"只推到期卡；
- **需求驱动**：词伙库按写作场景（表达好处/坏处/原因/解决…）组织——先有表达需求，再给语言。

1. **结构是免费的分**：任何题都是 4 段 13-15 句（2+5+5+1）。先花 10 分钟把"每段写什么"想清楚，写只是把提纲翻译成英语——把"想"和"写"分开是提速提分的第一要务。
2. **连接词不值钱，词伙才值钱**：Simon 30 篇 9 分范文中 Moreover 出现 0 次；band 7 词汇 = "考官想不到考生会写的主题搭配"（如 delay the development of a child's first language）。
3. **"提及"不等于"论证"**：每个观点必须有 explain + example 才算展开。TR 上不了 7 的作文，90% 死在这一条。

## 三点五、评分已用官方样卷校准（2026-09）

从剑10-13 书后答案提取 **27 篇官方样卷**（13 篇 Task 2 + 13 篇 Task 1 考生手写卷，Band 3.5-8，经视觉转录；+ 6 篇考官 9 分范文），让评分系统在**看不到官方分数**的条件下盲评：

- **AI 按本工具评分标准盲评：总分 MAE 0.05、无系统性偏移**（3.5~9 全段吻合，考官范文全给 9）——按 AI 精批的分数提分不会跑偏；
- 规则引擎 MAE 0.79，定位为“下限保护”：它报的问题一定是问题，但它识别不了优秀；
- GRA 分项 AI 天然略严 0.25，已知悉并在提示词中声明。

详见《knowledge/12-评分校准报告.md》，复跑命令：`node grade-rule.js`（规则）/ 校准语料在 `calibration/`。

## 五、诚实说明（工具的边界）

- 诊断室的机器扫描是**规则启发式**，能可靠抓住硬伤（字数不足、结构失衡、Although...but、逗号粘连、不可数名词、立场缺失、例子缺失、词伙覆盖、Task 1 的 overview 缺失/照抄题目/主谓逻辑等），但**不能替代人工精读**——最终分数由"机器扫描 + 20 项自评清单"共同得出，工具里也明确标注了这一点。
- 剑桥 14/16/18 原书 PDF 是扫描版无文字层，剑 14-18 题干已用网络多源（engnovate / ieltsessaybank / howtodoielts）交叉核实替换记忆版；Task 1 图表类型按调研标注、题干文字需配原书图表。考场真题为考生回忆，个别措辞可能与原题有出入。
- AI 精批为真实 API 调用（key 存于本机 tool/js/config.js，可在「AI 设置」覆盖）；模型评分存在 ±0.5 浮动，与规则诊断+自评交叉使用更可靠。deepseek-flash 为推理模型，精批约需 15-30 秒。
- Simon 原博客已于 2025 年 9 月因托管商倒闭下线，本项目的增量调研全部来自 Wayback Machine 归档实抓（见 knowledge/09）；"9+12 讲"视频课打包为第三方版本，官方课程目录见 09 号文档。
- 视频课（mp4）未转录，但其内容与 PDF 课程/worksheets 完全同源，无信息损失。
