# 电脑端写作工作台 · v1.2.0

## 使用方式

打开 `tool/index.html` 即可使用，建议使用电脑浏览器。首页可以继续训练、查看复测任务或进入写作室；侧栏保留原有八个功能。

写作室的连续编辑区支持自由分段。输入后自动保存，也可手动重试保存或复制全文。专注模式收起导航和教学面板，Escape 退出；逐段教学仍沿用四段数据，并保留独立初稿。

诊断后点击侧栏批注定位原句，点击标记选中批注。同一片段多次出现时可选择位置；无法匹配的引用会明确提示。点击「并排改写」编写个人版本，参考示范默认折叠。原稿始终是诊断时的快照；输入修改后，旧反馈显示版本提示。AI 生成可取消、重试，取消后的结果不会覆盖页面。

## 数据与实现

- 现有 `iwc_` 数据键、题目键和备份方式继续使用；新增 `iwc_revisions` 保存与原稿绑定的个人改写，自动包含在全量备份中。
- 共享桌面组件在 `tool/js/workbench.js`，界面样式在 `tool/css/workbench.css`。`EssayEditor` 提供全文读写、输入订阅和选区恢复；教学段落通过适配层保留原数组结构。
- `Store.set` 与保存记录、草稿接口返回布尔值，供界面显示保存是否成功。
- AI 服务与接口不变。测试使用模拟返回，不产生真实评阅费用。
- 字体使用系统字体和 Georgia，图标使用内联 SVG；不增加在线字体或图片依赖。完整 token、组件与禁止清单见根目录 `DESIGN.md`。

## 验证与构建

`npm test` 检查核心逻辑、语料与学习状态。`npm run test:e2e` 覆盖既有流程和桌面工作台的保存、批注、确认窗口、取消请求、主题与窗口宽度。

`python -X utf8 build_site.py` 生成 `dist/`，使用 v1.2.0 缓存名并收集新增 CSS / JS。此次交付为本地代码与构建，不包含线上发布。桌面验收截图位于 `.impeccable/review/`，示例作文与 AI 反馈为测试数据。

2026-10-01 的补充验收覆盖动态卡片键盘操作、收藏与设置保存失败、训练退出失败保留、旧导师请求与新请求并发、新稿刷新恢复和首页任务更新。缓存指纹包含实际资源内容，同版本的修复也会生成新缓存；断网测试确认新样式与共享脚本仍可加载。

规范化视觉 token 和组件预览位于根目录 `DESIGN.md` 与 `.impeccable/design.json`。完整验收结果见 `docs/desktop-acceptance.md`。
