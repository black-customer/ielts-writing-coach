# 电脑端体验优化 · v1.4.0

日期：2026-10-02。

## 长期平台范围

本项目默认面向电脑端浏览器。不规划、不开发手机端 App，手机端专项设计、适配和验收不纳入默认开发范围。只有项目所有者明确重新提出手机端需求时，才能调整此约束。不得因通用最佳实践、工具建议或框架能力而自行扩展手机端开发范围。

约束已进入 AGENTS.md、PRODUCT.md、README.md 和 DESIGN.md。现有窄屏回退保留；手机端不进入本轮开发和验收。

## 内容依据与取舍

评分表述核对 [IELTS 官方写作量表](https://ielts.org/cdn/ielts-guides/ielts-writing-band-descriptors.pdf)。模板和教学建议不构成固定扣分规则。修正了旧读图课与当前范文不一致的概括，例如剑18 Test 2 的收入组排序；移除立场由词伙数量决定、固定语态得分和多模型均分达标保证。

56 篇范文正文、词数、逐段引文和表达关联保持不变；精修自查指令及七处解释。28 份读图课由 models/t1-reading-lessons.json 生成，现有范文构建命令同时重建读图课，避免后续构建恢复旧提示。24 个话题扫描发现环境类同组重复观点，生成器按同组英文表达去重；跨话题或不同用途保持独立。

## 数据与架构

沿用静态架构、原 AI 服务和 iwc_ 数据命名。草稿增加可选题目来源与图表关联，旧格式继续恢复。最多保留 30 份换题原稿，随现有 JSON 备份导出。导入先验证全部条目，写入失败时尝试恢复原数据；恢复失败明确提示可能部分更新。

没有新增运行时依赖或一级导航。截图、临时脚本和测试报告留在忽略目录，发布仓库只包含源码、内容源文件和必要说明。

## 验收与发布

验收命令为 python -X utf8 run_checks.py、python -X utf8 build_site.py、npx playwright test。API 状态使用模拟返回，未进行真实付费评分测试，也不据此声称实际提分效果。

125% 缩放通过 1280/1440/1600px 物理窗口对应的 1024/1152/1280px CSS 视口检查布局，属于自动化等效检查。视觉截图覆盖主要页面的明暗主题与三档电脑宽度；不代表完整辅助技术认证。

本地完整回归：59 项端到端测试通过；逻辑、语料、学习与电脑体验、构建及发布保护合计 97 项检查通过；内容门禁 4862 项通过。站点构建为 v1.4.0，87 个离线预缓存资源。视觉复核后补齐搜索框的深色主题样式，六项宽度与主题组合复核通过。

设计检测只提示字号、圆角与已有深色状态色的文档化建议，没有阻断项；新增阅读角色和界面行为已同步 DESIGN.md 与配套配置。

常规 Git 传输在当前网络不可用，发布使用项目已有的 Git Data API 方案。远端 52 处差异经逐文件比较确认仅为换行差异，没有需要合并的内容冲突。上传使用本地已提交的内容，以内容哈希验证文件，保留远端树和父提交；远端分支发生变化则停止，始终禁止强制更新。最终 GitHub 提交与部署链接在交付消息中提供。
