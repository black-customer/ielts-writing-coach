# 写作学习闭环优化：实现与验收对应

本轮沿用本地静态站点和视觉体系。主流程为独立写作、理解反馈、亲自修改、检查修改、新题验证；可以分多天完成。没有使用真实付费 AI 请求，没有进行线上发布。

## 使用方式

首页继续最近作品；新用户直接选题。选题后直接写，自带 Task 1 / Task 2 题目与完整限时、双任务模考均有入口。电脑工作台中题目与正文并列，长图可放大，帮助默认收起。

写完可使用基础规则检查、站内 AI，或复制完整材料到网页 AI。外部回复可以作为可选备注，回来后直接修改。反馈只优先展开少量问题，点击定位原句；“问清楚”只讨论当前评阅原稿，不会替换正文。

“在原稿上修改”以原稿为起点，保留用户主动清空的状态。“检查这次修改”请求语义复核，返回改善状态、证据和下一步；无配置或离线时使用“复制复核材料”。原稿和修改都保留，可查看段落差异。旧规则检查不能证明论证问题解决。

随时保存返回，首页恢复作品、反馈、选中问题、修改稿和编辑位置。查看提示或范文的情况只记录在本产品内，外部帮助可选自报；不声称能够监测外部行为。新题优先排除本产品内已写和已打开同题材料的题目。记录不完整显示独立性未知。

已有8节原创课程的文字讲解与练习也可在帮助面板中按需展开，随站点离线打包；原有独立课程与视频文件保持原位置，不作为开始写作的必经步骤。

作品记录支持选择版本继续写、两篇作品比较、去除既有分数的盲评材料、查看旧反馈和历史对话。旧评分、词本、结构化自查与固定间隔复习保留为次级辅助，不阻塞主流程。

## 图表证据说明

对 48 张本地展示材料进行了概览核对。旧绘图规格存在明确不一致，不能作为 AI 事实来源。6 题文字描述逐项核对后启用：剑10 Test 2（表格）、剑12 Test 4（流程）、剑13 Test 4（地图）、剑15 Test 4（饼图＋表格）、剑17 Test 2（预算表＋饼图）、剑21 Test 4（饼图＋满意度表）。

其余 42 题未启用事实核验：仍可查看原图、写作和获得语言建议，AI 输入明确缺少可靠数据。每题状态与原因在 data-chart-evidence.js；不静默把近似重绘当原图。自带图说明标为用户补充；本轮没有增加图像识别接口。

## 数据与请求边界

作品版本保留在本机 localStorage，空间耗尽会显示失败并保留页面文本，需要复制或备份。同一会话未提交的自动保存更新工作草稿，避免每次敲字存一份全文；已绑定反馈的原稿、导入版本和其他标签页的冲突版本保留。迁移不删除旧键；关联只使用明确身份或相同任务、题目、原文，不做相似匹配。失败作品保留内存可重试。跨标签页冲突保留双方版本，备注冲突保留另一份备注。

AI 仅在主动提交时调用已有 DeepSeek 兼容接口。追问使用普通文本输出，复核使用小型 JSON，不套完整评分报告。请求90秒超时；对话输入最多28,000字符（保守预算，不是模型 token 精确值），超出要求新开一轮，保留历史。切页取消追问与复核；完整评阅迟到时保存原版本，不覆盖新作文。

## 本轮验收结果

2026-10-15：`npm test`、`python -X utf8 run_checks.py`、`python -X utf8 build_site.py` 均通过；完整端到端68场景通过。最后针对帮助面板即时保存、追问、修改复核及恢复补充复验，新工作台9场景全部通过。`git diff --check` 无错误。

桌面覆盖1280、1440、1600px、明暗主题、125%缩放布局；构建产物完成 Service Worker 预缓存和断网恢复验证。AI 均为模拟响应，没有真实 API 消费。视觉复核图及浏览器报告只保存在忽略的本地验收目录，不包含在交付上传中。

## 真实效果验证协议

招募有真实雅思写作需求的电脑用户，记录当前写作水平及熟悉工具程度。准备难度相近、未提前看范文的两组题；每位用户都使用普通文档＋网页 AI 和新版工作台，顺序交叉，使用同一 AI、相同反馈要求，避免模型能力差异。

每种方式包含独立初稿、反馈、本人修改及隔天恢复；一周后使用陌生题进行延迟独立写作。人工记录准备到开写、找到反馈原句、开始修改、恢复练习的耗时，以及是否完成修改、请求帮助和再次练习。学习时间与事务操作时间分别记录。

延迟作品移除工具、既有评分与用户身份，交给同一可靠评价者盲评任务回应、组织、表达和语言准确性，Task 1/2分开。比较实际执行量、退出位置和独立作品表现，同时记录题目难度与评分不确定性。先小范围找明显摩擦再决定扩样，不由几次 AI 参考分上涨推断提分效果。不新增远程埋点；使用自愿、去标识记录。
