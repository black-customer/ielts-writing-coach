# Desktop workbench
Mode: Operate. Target: tool/index.html. Desktop only.

## Direction contract
THESIS: 让作文与可定位的反馈在同一工作台内连续处理。用户已锁定方向；不重新选择风格。
OWN-WORLD: #F3F5F7 雾灰、#FFFFFF 纸白、#202936 墨色、#294D73 深蓝、#647080 辅助文字、#DCE2E8 分隔线。系统 UI 字体与 Georgia 英文正文；统一细线 SVG 图标，纸张式编辑区。
STORY: 今日目标 → 独立作答 → 定位反馈 → 个人改写 → 换题复测。
FIRST VIEWPORT: 216px 固定侧栏；首页一项明确任务与继续草稿；写作页中央连续正文、顶部题目、底部状态，336px 可收起教学栏。
FORM: 用户明确采用电脑写作工作台，优先于 seed 33303210 的随机分配。Signature: 点击批注准确定位原句，点击标记选中批注。动效 180ms，减少动态效果时取消。
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

PLATFORM POLICY: 默认只考虑电脑端浏览器；只有项目所有者明确重新要求，才规划手机端 App、专项适配和验收。
V1.4: 首要任务与草稿优先，完整选题默认折叠；范文组合搜索与分页，批注合并并给出可执行自查。
